# tea-pos v2

The rebuild of tea-pos: Vite and React static apps on Cloudflare Pages, a Go backend on Railway, Supabase for the database, login and files.

The plan, every decision and its reason live in the RFC: [Next architecture for the tea-pos app suite](https://app.notion.com/p/3f495a715405812eae99d02d37240af8). Each build step has its plan in `.claude/tasks/`.
